# GarrisonFarm GPU 加速版 v1.3

把明日方舟「卫戍协议」自动刷角标工具的**文字识别从 CPU 搬到显卡**上运行的版本。

> 本仓库是 [FJH3576/GarrisonFarm-Personal](https://github.com/FJH3576/GarrisonFarm-Personal) **v1.2 个人优化版**的非官方修改构建。
> 程序本身的功能、逻辑、界面**完全没有任何改动**，只替换了 OCR 的推理后端（CPU → DirectML GPU）。

---

## 一、为什么会有这个版本

原版程序内置的是 `rapidocr + onnxruntime` 的 **CPU 版**推理库，且 `config.yaml` 里线程数为 `-1`（不限制线程）。
结果是：**每一次文字识别都会把所有 CPU 核心拉满**。

实测原版在准备阶段刷新商店时（截图 → 读 5 张卡 → 读资金）：
- 耗时约 **0.66 秒**，CPU 占用约 **3.8 秒**（相当于 5~6 个核心满载）；
- 一回合要刷新十几次商店，于是 CPU 长时间 100%，机器风扇狂转、其它软件卡顿。

识别本身占的时间并不多，CPU 是被"算力浪费在空闲线程争抢"上吃掉的，所以最合适的解法就是换 GPU 推理。

## 二、相对上游 v1.2 到底改了什么

只有两处，且不涉及任何程序代码：

| # | 文件 / 目录 | 改动 |
|---|---|---|
| 1 | `_internal/onnxruntime/` | 由 `onnxruntime 1.19.2 (CPU)` 替换为 **`onnxruntime-directml 1.19.2`**（版本号完全对应，接口一致） |
| 2 | `_internal/rapidocr_onnxruntime/config.yaml` | `use_dml: false` → `use_dml: true`（检测 / 方向 / 识别 三处） |

- 没有修改 `GarrisonFarm.exe`，没有修改任何 `.pyc` 字节码，没有动识别模型和坐标；
- 用的是 **DirectML**（Windows 自带的 DX12 推理后端），**不需要装 CUDA / cuDNN**，NVIDIA / AMD / Intel 显卡都能用；
- 识别文字与 CPU 版**逐条完全一致**（5 个区域比对无差异），不存在准确率下降。

## 三、实测效果

测试环境：Windows + RTX 4060 Ti + Ryzen 5 7500F（6 核 12 线程）+ MuMu 模拟器 12，1920×1080 同一帧画面。

| 识别区域 | 原版 v1.2（CPU） | 本版本（DirectML） |
|---|---|---|
| 商店 5 张卡 | 551 ms / **2975 ms CPU**（≈5.4 核） | 162 ms / **185 ms**（≈1.1 核） |
| 右上信息面板 | 132 ms / 965 ms（≈7.3 核） | 98 ms / 123 ms |
| 资金数字 | 99 ms / 773 ms（≈7.8 核） | 73 ms / 74 ms |
| 顶部回合 / 资金 | 369 ms / 2031 ms（≈5.5 核） | 166 ms / 166 ms |

**一次"刷新商店"的完整开销：0.66 秒 / 3.8 秒 CPU → 0.28 秒 / 0.35 秒 CPU。**

即：CPU 从 5~6 个核心满载降到 1 个核心上下，同时识别速度快了 2~3 倍，准备阶段也随之变快。

## 四、下载与使用

1. 到 [**Releases**](../../releases) 下载 `GarrisonFarm-GPU-v1.3.zip`（约 85 MB，解压后目录名 `GarrisonFarm_GPU加速版v1.3`）；
2. 解压到任意目录（路径别带特殊字符），保持目录结构不变；
3. 双击 `开始刷角标.bat` 正常使用，其余用法与原版完全一致（模拟器连接、`settings.json` 配置等都没有变化）。

**怎么确认真的在用显卡**：启动日志里会出现三行

```
OrtInferSession - INFO: Windows 10 or above detected, try to use DirectML as primary provider
```

同时任务管理器里 `GarrisonFarm.exe` 的 CPU 应该只在 1 个核心上下波动，而不是原来的全核 100%。

## 五、想退回 CPU / 想进一步压 CPU

包里自带三个小工具（`工具`说明见 `使用说明.txt`）：

- `还原CPU版.bat`：一键恢复成原版的 CPU 推理（原库和原配置都已备份在程序目录里，可反复来回切换）；
- `安装GPU加速.bat`：给**你自己的** v1.1 / v1.2 原版程序打补丁（补丁文件在 Release 附件 `gpu_files.zip`，解压到脚本同目录即可）；
- `备用-限制CPU线程.bat`：不想用 GPU 时，把 OCR 线程数限制成 2 / 4 / 6，降低 CPU 峰值（代价是识别变慢）。

## 六、环境要求与注意事项

- Windows 10 及以上，显卡需支持 **DirectX 12**，显卡驱动保持较新（NVIDIA 472+ 均可）；
- 本版本只对应上游 **v1.2**。上游若发布新版本，`_internal` 结构可能变化，补丁需要重打；
- 补丁不联网、不写注册表、不改系统文件，所有改动都在程序目录内；
- 模拟器、游戏账号相关的一切仍由原程序处理，与本修改无关。
